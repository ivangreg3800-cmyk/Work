    Контракт вашего эндпоинта

    Задайте метод, путь и ответ. После сохранения эндпоинт можно вызвать во вкладке «Запросы».

    Поддерживаются пути с параметрами, например /users/{id}. Ответ — заданный вами JSON-пример. Поля запроса проверяются на наличие; бизнес-логику эндпоинта песочница не генерирует.

    Мои эндпоинты

    Документация API

    Контракт OpenAPI 3.0.3 включает учебные и ваши эндпоинты, параметры, тела запросов и ответы.

    Адрес api.example.com — пример для документации. Замените его адресом вашего сервера при реализации API. Внешние клиенты не могут обращаться к локальной песочнице.
