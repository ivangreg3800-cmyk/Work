# ВерПрактикум SQL · BPMN · API · Python

Интерактивный учебный сайт на русском языке.

Рабочая версия: https://sql-praktikum.ivverbit9090.chatgpt.site
Доступ к рабочей версии управляется в ChatGPT Sites.

## Возможности

- SQL: 26 заданий, SQLite (sql.js / WebAssembly), проверка результата, подсказки и справочник.
- BPMN: 15 сценариев, включая три процесса с 3–4 дорожками, редактор bpmn-js, проверка структуры и экспорт `.bpmn`.
- API: 12 заданий, включая пагинацию, идемпотентность, ETag/If-Match, роли и цепочки запросов, GET/POST/PUT/PATCH/DELETE, локальная песочница, собственные эндпоинты и экспорт OpenAPI 3.0.3.
- Подробный разбор каждого задания SQL, BPMN и API: шаги, эталонный подход и типичные ошибки.
- Python: 12 заданий (основы, практика и алгоритмы), теория, код в Web Worker с Pyodide 0.29.3, автоматические тесты и подробные разборы. При первом запуске необходим доступ к cdn.jsdelivr.net; внешние пакеты для заданий не нужны. Проверяется возвращаемый результат, а не конкретный алгоритм.
- Теория: пять глав об идентификации и доступе, архитектуре, API и обмене сообщениями (ESB, Kafka, RabbitMQ) и работе бизнес-аналитика от запроса до передачи требований. Примеры, сравнительные таблицы, разборы ситуаций и ссылки на первоисточники. В каждой главе — интерактивная SVG-схема с пошаговыми пояснениями, сценариями и управляемой анимацией.
- Адаптивный интерфейс и локальное сохранение прогресса.

## Локальный запуск

Из этой папки выполните:

```sh
python3 -m http.server 8000 --directory public
```

Откройте http://localhost:8000 для локальной проверки тренажёров без авторизации. Production собирается командой `node scripts/build-auth.cjs`: Worker проверяет сессию перед выдачей каждого файла. Статический сервер не проверяет пароль и не подходит для закрытой публикации.
API-песочница использует Service Worker: требуется HTTPS либо localhost.
Не открывайте HTML напрямую через `file://`.

## Проверки

Требуется Node.js 20 или новее:

```sh
node tests/bpmn-validation.cjs
node tests/api-runtime.cjs
node tests/api-advanced.cjs
node tests/sql-advanced.cjs
node tests/auth.mjs
node tests/python-ui.cjs
```

Проверка всех 58 Python-кейсов в настоящем Pyodide: скачайте полный runtime версии 0.29.3 и выполните `PYODIDE_RUNTIME=/path/to/runtime node tests/python-runtime.cjs`.

## Структура

- `public/` — исходники интерфейса; не публиковать как открытые статические файлы.
- `server/auth.mjs` — общий вход, серверная проверка и подписанная сессия.
- `scripts/build-auth.cjs` — сборка Worker в `dist/server/index.js`.
- `public/bpmn/` — BPMN-тренажёр и правила проверки.
- `public/python/` — обучение Python, задания и изолированный от интерфейса поток исполнения.
- `public/api/` — API-тренажёр и Service Worker.
- `public/login/` — страница входа.
- `public/vendor/` — локальные зависимости.
- `tests/` — проверки BPMN и API.

## Особенности размещения

Приложение использует пути от корня домена. Публикуйте Worker, а не папку public. Все учебные файлы включены в серверный модуль и выдаются только после проверки сессии; отдельного публичного хранилища ресурсов нет.

В production требуются SHARED_LOGIN, SHARED_PASSWORD (от 12 символов) и SESSION_SECRET (случайный секрет от 32 символов). Задавайте их как секреты окружения, не коммитьте значения. Сессия действует 12 часов, cookie имеет HttpOnly, Secure, SameSite=Strict. Смена любого секрета инвалидирует старые сессии. Лимит попыток входа действует в пределах экземпляра Worker и не является глобальным распределённым ограничением.

Для посетителей без ChatGPT после настройки секретов требуется режим доступа public на платформе. До настройки данных входа сохраняйте закрытый режим. Без секретов приложение не выдаёт учебные материалы. Общий пароль выдаёт владелец, самостоятельной регистрации нет.

Прогресс, черновики и данные песочницы хранятся в localStorage браузера. Синхронизации между устройствами нет. API-песочница — локальная симуляция, а не внешний API-сервер. Свои эндпоинты возвращают заданные JSON-примеры и проверяют наличие обязательных полей; произвольная серверная бизнес-логика не исполняется.

## Зависимости

- sql.js 1.13.0 — SQLite в WebAssembly (MIT).
- bpmn-js 18.16.0 — BPMN-редактор; условия в `dist/vendor/bpmn/LICENSE`. Знак bpmn.io сохранён.
- Golos Text и JetBrains Mono загружаются через Google Fonts; предусмотрены системные шрифты.

В репозиторий не включены служебные настройки ChatGPT Sites, ключи, токены и пользовательские данные браузера.


## UML и ER

`/uml/`: шесть заданий по ER-моделированию и UML Use Case. Векторный редактор с перемещением мышью/касанием и клавиатурой, редактированием полей PK/FK, кратностями, ассоциациями, include/extend и границей системы. Проверка заданной модели, объяснения ошибок, пошаговые разборы с эталонными схемами, отмена, SVG-экспорт. Черновики и прогресс сохраняются локально. ER представлен отдельной моделью данных, не видом UML. Проверяется учебная спецификация с фиксированными названиями и составом; произвольные эквивалентные модели не оцениваются.
