# Практикум SQL · BPMN · API

Интерактивный учебный сайт на русском языке.

Рабочая версия: https://sql-praktikum.ivverbit9090.chatgpt.site
Доступ к рабочей версии управляется в ChatGPT Sites.

## Возможности

- SQL: 18 заданий, SQLite (sql.js / WebAssembly), проверка результата, подсказки и справочник.
- BPMN: 8 сценариев, редактор bpmn-js, проверка структуры и экспорт `.bpmn`.
- API: 6 заданий, GET/POST/PUT/PATCH/DELETE, локальная песочница, собственные эндпоинты и экспорт OpenAPI 3.0.3.
- Адаптивный интерфейс и локальное сохранение прогресса.

## Локальный запуск

Из этой папки выполните:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Сборка и установка npm-пакетов не нужны.
API-песочница использует Service Worker: требуется HTTPS либо localhost.
Не открывайте HTML напрямую через `file://`.

## Проверки

Требуется Node.js 20 или новее:

```sh
node tests/bpmn-validation.cjs
node tests/api-runtime.cjs
```

## Структура

- `dist/` — готовые статические файлы и исходники приложения.
- `dist/bpmn/` — BPMN-тренажёр и правила проверки.
- `dist/api/` — API-тренажёр и Service Worker.
- `dist/login/` — страница входа.
- `dist/vendor/` — локальные зависимости.
- `tests/` — проверки BPMN и API.

## Особенности размещения

Приложение использует абсолютные пути от корня домена (`/bpmn/`, `/api/`). На другом хостинге публикуйте содержимое `dist` в корне домена. Для размещения в подпапке GitHub Pages потребуется адаптировать пути, область Service Worker и пути его запросов.

Вход через ChatGPT обслуживается платформой ChatGPT Sites: `/signin-with-chatgpt` и `/signout-with-chatgpt`. Эти маршруты не реализованы в статических файлах и не будут работать сами по себе на GitHub Pages или другом хостинге. Для переноса авторизации нужна отдельная интеграция. Публикация исходников в этом репозитории не включает и не настраивает GitHub Pages.

Прогресс, черновики и данные песочницы хранятся в localStorage браузера. Синхронизации между устройствами нет. API-песочница — локальная симуляция, а не внешний API-сервер. Свои эндпоинты возвращают заданные JSON-примеры и проверяют наличие обязательных полей; произвольная серверная бизнес-логика не исполняется.
